# Longer Sessions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stay logged in on a trusted device while the app is used at least once every 30 days, add "log out everywhere", and send the user to the login screen whenever a session ends.

**Architecture:** The JWT in the `access_token` cookie gains `ver`, `rm` and `iat` claims. `get_current_user` reissues the token on every authenticated request (sliding window) and rejects tokens whose `ver` differs from the new `users.token_version` column. The frontend gets a "Keep me logged in" checkbox, a "Log out everywhere" button, and a `QueryClient` whose cache-level `onError` handlers turn any 401 into a trip to the login screen.

**Tech Stack:** FastAPI 0.141, PyJWT 2.13, SQLAlchemy 2, Alembic, pytest; React 19, TanStack Query 5.102, React Hook Form + Zod 4, Vitest + RTL + MSW 2.

Spec: `docs/superpowers/specs/2026-10-13-longer-sessions-design.md`.

## Global Constraints

- Auth stays a JWT in an httpOnly cookie named `access_token`, `SameSite=Lax`, `Path=/`, `Secure` only when `ENVIRONMENT=production`. No token or auth state in JavaScript; `GET /api/auth/me` stays the source of truth.
- Token claims: `sub` (user id string), `exp`, `iat`, `ver` (the user's `token_version`), `rm` (bool).
- Remembered session (`rm: true`): idle limit `remember_days` days (new setting, default 30); persistent cookie, `max_age = remember_days * 86400`.
- Short session (`rm: false`): idle limit `jwt_expire_minutes` (existing, default 60); browser-session cookie with no `max_age`.
- `UserLogin` gains `remember: bool = False`. Register always issues `rm: false`.
- `users.token_version`: integer, not null, server default `0`. A token whose `ver` is missing or differs gets 401.
- `POST /api/auth/logout` is unchanged. New `POST /api/auth/logout-all` requires auth, increments `token_version`, deletes this device's cookie, returns 204.
- UI copy, exact: checkbox "Keep me logged in" (unticked by default); button "Log out everywhere"; confirmation text "This logs out every device, including this one."; buttons "Confirm" and "Cancel".
- Layering: routers are thin; services raise domain exceptions, never `HTTPException`.
- Backend tooling runs from `backend/` with `uv run ...`. Ruff must be clean (`uv run ruff check . && uv run ruff format --check .`).
- `frontend/src/api/schema.d.ts` is generated (`npm run gen:api`), never hand-edited.
- Never read or edit any `.env` or `.env.example` file. No new environment variables.
- Read every Alembic migration before `upgrade head`.
- Conventional commits; every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```python
def session_lifetime(remember: bool) -> timedelta:
    if remember:
        return timedelta(days=settings.remember_days)
    return timedelta(minutes=settings.jwt_expire_minutes)


def create_token(user: User, remember: bool) -> str:
    now = datetime.now(UTC)
    claims = {
        "sub": str(user.id),
        "iat": now,
        "exp": now + session_lifetime(remember),
        "ver": user.token_version,
        "rm": remember,
    }
    return jwt.encode(claims, settings.jwt_secret, algorithm="HS256")


def start_session(response: Response, user: User, remember: bool) -> None:
    # A remembered session gets a persistent cookie. Otherwise the cookie lasts
    # until the browser closes and the token's exp is the idle limit.
    max_age = int(session_lifetime(remember).total_seconds()) if remember else None
    response.set_cookie(
        key=COOKIE_NAME,
        value=create_token(user, remember),
        httponly=True,
        samesite="lax",
        secure=settings.environment == "production",
        max_age=max_age,
        path="/",
    )


def get_current_user(
    request: Request, response: Response, db: Session = Depends(get_db)
) -> User:
    token = request.cookies.get(COOKIE_NAME)
    if not token:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "Not Authenticated")
    try:
        payload = jwt.decode(
            token,
            settings.jwt_secret,
            algorithms=["HS256"],
            options={"require": ["exp", "sub", "ver", "rm"]},
        )
    except jwt.PyJWTError:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "Invalid or expired")
    user = db.get(User, int(payload["sub"]))
    if user is None:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "User no longer exists")
    if payload["ver"] != user.token_version:
        raise HTTPException(status.HTTP_401_UNAUTHORIZED, "Session ended")
    # Sliding window: every authenticated request pushes the expiry forward.
    start_session(response, user, remember=payload["rm"] is True)
    return user
```

FastAPI merges cookies set on a dependency's `Response` into the route's response, including 204 responses (verified on FastAPI 0.141.1 during planning).

def log_out_everywhere(db: Session, user: User) -> None:
    # Every token carries the version it was issued with, so incrementing the
    # version invalidates all of them at once.
    db.execute(
        update(User)
        .where(User.id == user.id)
        .values(token_version=User.token_version + 1)

```markdown
# 20. Sliding sessions, remember me, and log out everywhere

- **Date:** 2026-10-13
- **Status:** Accepted (amends the session lifetime in [record 2](0002-jwt-in-httponly-cookie.md))

## Context

Sessions lasted 60 minutes from login and nothing renewed them, so the iPhone home-screen app
logged out every hour, even mid-use. Record 2 accepted that a logged-out token stays valid
until it expires because 60 minutes is short; a month-long session changes that tradeoff.

The app is reachable only from my own tailnet devices, so a stolen cookie is usable only from
one of them. That makes long sessions cheaper here than on a public site, not free.

## Decision

- **Sliding window.** Every authenticated request reissues the token with a fresh expiry, so a
  session ends only after a full idle period.
- **"Keep me logged in" decides the period.** Ticked: 30 days idle (`remember_days`) and a
  persistent cookie. Unticked: 60 minutes idle and a cookie that ends with the browser.
- **Keep the stateless JWT** and add `users.token_version`. Each token carries the version it
  was issued with; "log out everywhere" increments it, so every outstanding token is rejected.
  The check is free because the user row is already loaded on every request.
- **No absolute cap** on session age; log out everywhere covers a lost device.
- The frontend sends the user to the login screen on any 401, instead of showing the raw error.

## Alternatives considered

- **Server-side sessions table** (opaque token, hashed in the database). Logout would kill the
  token everywhere, and Settings could list devices and end one. More code and a reversal of
  record 2's token choice; for one user on two devices, log out everywhere is enough.
- **Short access token plus a rotating refresh token.** The standard answer when many services
  verify tokens without a database. Here there is one API and it reads the database on every
  request anyway, so it would add the complexity of both designs without that benefit.
- **A longer fixed expiry** (log in once a month regardless of use). Simplest, but logs out an
  app in daily use, and still has no way to end a stolen session early.

## Consequences

- Logout still only deletes the cookie on that device; a copied token stays valid for up to 30
  days unless log out everywhere is used.
- There is no list of signed-in devices and no way to end just one.
- Every device was logged out once at deploy, because older tokens have no version.
- Every authenticated response sets a cookie.
```

- [ ] **Step 4: Create the query client module**

Create `frontend/src/api/queryClient.ts`:

```ts
import { MutationCache, QueryCache, QueryClient } from "@tanstack/react-query";
import { loginMutationKey, meQueryKey } from "./auth";
import { ApiError } from "./client";

function isUnauthorized(error: unknown): boolean {
  return error instanceof ApiError && error.status === 401;
}

// The session ended (expired, or logged out everywhere). Drop the cached data
// and let /me find out: its 401 makes RequireAuth redirect to /login.
function endSession(queryClient: QueryClient) {
  queryClient.removeQueries({ predicate: (query) => query.queryKey[0] !== meQueryKey[0] });
  void queryClient.invalidateQueries({ queryKey: meQueryKey });
}

export function createQueryClient(): QueryClient {
  const queryClient: QueryClient = new QueryClient({
    defaultOptions: {
      // Retrying a 401 only delays the redirect; other errors keep the default 3 retries.
      queries: { retry: (failureCount, error) => !isUnauthorized(error) && failureCount < 3 },
    },
    queryCache: new QueryCache({
      onError: (error, query) => {
        // /me's own 401 is handled by RequireAuth; reacting here would loop.
        if (isUnauthorized(error) && query.queryKey[0] !== meQueryKey[0]) endSession(queryClient);
      },
    }),
    mutationCache: new MutationCache({
      onError: (error, _variables, _onMutateResult, mutation) => {
        if (isUnauthorized(error) && mutation.options.mutationKey?.[0] !== loginMutationKey[0]) {
          endSession(queryClient);
        }
      },
    }),
  });
  return queryClient;
}
```
