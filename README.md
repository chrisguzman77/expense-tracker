# Expense Tracker

Personal expense tracking. Single user, log expenses, see monthly spend by category.

## Scope

- In: accounts, add/list/delete expenses, monthly category summary
- Out (v2 ideas): bank import, recurring, budgets, multi-currency

## Stack

FastAPI + SQLAlchemy + Postgres / React + TypeScript + Vite / Docker Compose
